Bit Haven is a hackerspace in the Tri-Main building in Buffalo, NY.

The Bit Haven Dojo is a CTF platform hosted on the local network at the hackerspace.  

To access the Dojo, you need to be physically present at the hackerspace, and connected to the local network, usually via wifi like any normal person.

You can create a Dojo user account like any website and participate in solving challenges within minutes.

Challenges are created by hackerspace members.
