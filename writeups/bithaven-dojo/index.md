# BitHaven Dojo

Bit Haven is a hackerspace in the Tri-Main building in Buffalo, NY.

A hackerspace is a community-operated workspace where people with shared interests in technology, science, and art can meet, collaborate, and work on projects. These spaces often provide tools and resources for members to learn from each other and create together.

Bit Haven is a cybersecurity-oriented hackerspace, with stuff like lock-picking stations and CTF participation events, but they also have soldering stations for general purpose electronics hardware hacking, and general purpose workstations for all manner of computer related shenanigans.

The Bit Haven Dojo is a CTF platform hosted on the local network at the hackerspace.  

To access the Dojo, you need to be physically present at the hackerspace, and connected to the local network, usually via wifi like any normal person.

You can create a Dojo user account like on many websites, and participate in solving challenges within minutes.

Challenges are created by hackerspace members.
